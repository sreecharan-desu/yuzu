# Yuzu field notes

Yuzu is a **citrus** fruit with an *intensely fragrant* rind. See [the reference](https://example.com/yuzu).

## Where it grows

- Japan, especially Kochi
- Korea, where it is called yuja
- China, its likely origin

## Uses

1. Ponzu sauce
2. Yuzu kosho

> Picked in late autumn.

```
ratio = juice / weight
```
