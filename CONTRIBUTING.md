# Contributing to Yuzu

Thanks for helping make Yuzu better.

## Reporting bugs and ideas

Open an issue with the bug or feature template. For bugs, include your macOS version, the Yuzu version
(Settings > About), the file type you were working with, and what you expected to happen.

## Development setup

```sh
brew install xcodegen create-dmg ffmpeg webp exiftool
scripts/build.sh            # universal Release build (Intel and Apple Silicon), macOS 13 deployment target, ad-hoc signed
open dist/Yuzu.app
```

`project.yml` is the source of truth for the Xcode project; `Yuzu.xcodeproj` is generated and not committed.

## Testing

- `scripts/make-fixtures.sh` generates one small sample file per supported format into `TestFiles/formats`.
- Launch the app with `-YuzuDebugHooks YES` to enable the local test hooks used by `scripts/yuzuctl.swift`
  (for example `build/bin/yuzuctl batch dir=... out=report.tsv` runs every conversion headlessly).
- `swift scripts/validate.swift report.tsv` opens every output with the right decoder and reports failures.

## Pull requests

- Keep changes focused, and describe what you changed and how you tested it.
- Follow the existing style: Swift, SwiftUI and AppKit, no third-party dependencies in the app.
- Everything must run locally. No network calls, analytics or telemetry.
- Only add assets you created yourself or that are generated by a script in this repo.
- Make sure `scripts/build.sh` succeeds with no warnings.
